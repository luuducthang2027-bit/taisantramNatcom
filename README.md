# Tài sản trạm Natcom

Tool so sánh tài sản trạm giữa các kỳ chốt, báo cáo kho xuất ra trạm, theo ngày, theo quyết định (DC), kế hoạch, nhân viên, mã chưa gán.

Lần đầu mở trên mỗi máy: vào **Nạp dữ liệu → Cài đặt**, dán link Apps Script (/exec) do Phòng QLTS cung cấp, bấm **Lưu cài đặt**.
Link và mật khẩu không lưu trong repo này.
