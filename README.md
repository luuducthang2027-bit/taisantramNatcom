# Tài sản trạm Natcom

Tool so sánh tài sản trạm giữa các kỳ chốt, báo cáo kho xuất ra trạm, theo ngày, theo quyết định (DC), kế hoạch, nhân viên, mã chưa gán.

Trang đã gắn sẵn link Apps Script mặc định (theo yêu cầu chủ repo). Muốn dùng link khác: **Nạp dữ liệu → Cài đặt** → dán link /exec → **Lưu cài đặt**.
Mật khẩu admin không lưu trong repo này (kiểm tra trên Apps Script).
