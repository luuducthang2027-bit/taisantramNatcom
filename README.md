# Tài sản trạm Natcom

Tool so sánh tài sản trạm giữa các kỳ chốt, báo cáo kho xuất ra trạm, theo ngày, theo quyết định (DC), kế hoạch, nhân viên, mã chưa gán.

- Bật GitHub Pages: Settings → Pages → Branch `main`, thư mục `/ (root)`.
- Dữ liệu lưu trên Google Sheet qua Apps Script; thư mục `data/` là bản sao lưu tự động từ Apps Script.
- Lần đầu mở trang: vào **Nạp dữ liệu → Cài đặt**, dán link Apps Script `/exec` (hoặc dùng bản đã gắn sẵn link).
